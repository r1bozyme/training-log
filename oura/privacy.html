Datenschutzerklärung / Privacy Policy

Training Log · Oura-Anbindung · Stand 25.10.2026

Zweck

Training Log ist eine private App, die ausschließlich vom Betreiber selbst genutzt wird. Die Oura-Anbindung liest die eigenen Ringdaten des Betreibers (Schlaf, Ruhepuls, HRV, Schritte), um sie im persönlichen Trainings- und Ernährungsprotokoll anzuzeigen.

Welche Daten

Nur die Datentypen, deren Freigabe bei der Oura-Anmeldung erteilt wird. Es werden keine Daten anderer Personen verarbeitet.

Speicherung

Die abgerufenen Tageswerte werden in einem privaten GitHub-Repository des Betreibers gespeichert. Zugangstokens liegen verschlüsselt bzw. als GitHub-Secrets vor.

Weitergabe

Keine Weitergabe an Dritte, keine Werbung, kein Tracking, keine Analyse-Dienste.

Widerruf und Löschung

Der Zugriff kann jederzeit in den Oura-Kontoeinstellungen widerrufen werden. Gespeicherte Daten werden auf Wunsch aus dem Repository gelöscht.

Summary (English)

Training Log is a private, single-user app. The Oura integration reads only the operator's own ring data (sleep, resting heart rate, HRV, steps) to display it in a personal training log. Data is stored in the operator's private GitHub repository, is never shared with third parties, and is not used for advertising or analytics. Access can be revoked at any time in the Oura account settings; stored data is deleted on request.
